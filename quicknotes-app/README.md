# QuickNotes

QuickNotes is a simple browser-based note-taking application that allows users to create, organize, search and delete notes. Notes can be categorized as Personal, Work or Study, and they are automatically saved in the browser's local storage so that they remain available after refreshing the page.

## Features

- Add new notes
- Categorize notes as Personal, Work or Study
- Search notes in real time
- Delete individual notes
- Validate empty notes
- Limit notes to 200 characters
- Display the total number of notes
- Display the date and time when each note was created
- Save notes using browser localStorage
- Restore notes after refreshing the page
- Responsive design for desktop and mobile devices
- Different visual styles for each note category
